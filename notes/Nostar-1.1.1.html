Aggiornamento consigliato

Nostar 1.1.1

Un rilascio di stabilizzazione per Project Hub, pacchetti progetto e aggiornamenti automatici.

Novita principali

  • Progetti portabili: puoi esportare e importare pacchetti .nostarproject con dati progetto, catalogo e configurazione locale. Le foto restano fuori dal pacchetto.
  • Apertura da Finder: doppio clic su un file .nostarproject e Nostar importa il progetto, apre Project Hub e lo seleziona automaticamente.
  • Collega codice Nostar: un progetto locale o importato puo essere associato a un codice cloud gia esistente senza fare pull automatici o sovrascrivere le impostazioni del progetto.

Miglioramenti

  • Note aggiornamento leggibili: la finestra Sparkle ora mostra queste note come pagina formattata, non piu come sorgente HTML.
  • Codici invito piu tolleranti: Nostar normalizza i codici copiati con spazi o senza trattino prima del collegamento.
  • Watcher cloud piu pulito: quando disabiliti il cloud sul progetto attivo, il watcher viene spento correttamente.

Qualita

  • Suite completa verificata prima del rilascio.
  • Flusso Project Hub coperto da test dedicati per import/export, credenziali locali e collegamento codice Nostar.
