Nostar 1.1.0

Rilascio foundation Q2: nuovo flusso project-first, scan più affidabile, export più controllato, profili cliente portabili e pulizia del vecchio layer LLM. SigLIP/CoreML resta il motore locale per la classificazione categoria.

Novità principali

  • Flusso project-first: l'app lavora attorno ai progetti. Il cambio progetto mantiene uno stato di caricamento dedicato e non mostra più stati vuoti fuorvianti durante lo switch.
  • Scan più robusto: la rilevazione cambi file usa data modifica e dimensione, preserva meglio cache e tombstone, e invalida i QC quando un file viene realmente sostituito.
  • Export aggiornato: gestione più sicura delle destinazioni, preset portabili, composer visuale della formula nome file e preflight più esplicito.
  • Profili cliente portabili: un progetto può esportare/importare il profilo cliente operativo, con QC, naming, viste e categoria Vision, senza portarsi dietro cataloghi SKU o file progetto.
  • Cloud/session sharing: il bundle cloud include impostazioni progetto e riferimenti al profilo cliente, così un Mac che entra nel progetto può ricostruire lo stato necessario.

Qualità e AI locale

  • SigLIP/CoreML: categoria AI trattata come suggerimento operativo senza warning di incertezza; il pool termini è più deterministico e allineato al modello CoreML.
  • Inspector: aggiunto overlay debug della maschera di segmentazione per analizzare il comportamento del background check.
  • Ricerca prodotti: migliorato il match su suffissi reali, alias categoria e nomi file.

Pulizia tecnica

  • Rimosso il vecchio layer LLM/RAG, inclusi servizi, viste diagnostiche, schema vector store e superfici debug legacy.
  • Il PDF linee guida resta asset cliente: non viene più usato per estrazione LLM.
  • Le impostazioni operative del progetto vengono lette dal progetto, non da default globali o template cliente a runtime.

Per forzare il check di aggiornamento via terminale:

defaults delete zannato.Nostar SULastCheckTime
