Nostar 1.0.5

Hotfix per il bottone "Rigenera suggerimenti" e per la categorizzazione automatica SigLIP sui progetti cloud appena creati.

Fix

  • Risolto: il bottone "Rigenera suggerimenti" nella tab Vision AI ora assegna effettivamente la categoria ai prodotti, oltre a generare i suggerimenti. Prima: i suggerimenti comparivano con confidence alta ma la tabella prodotti restava senza categoria. Ora: stesso comportamento del post-scan automatico.
  • Migliorata la robustezza del sync cloud per cataloghi grandi (lato server): batch D1 ridimensionati per evitare timeout di transazione, e la query di finalize è stata alleggerita per non superare il limite CPU di D1 su cataloghi con migliaia di SKU.

Note tecniche

Sotto il cofano: NostarPSVisionAITab.runRegeneration() ora chiama ProjectProductService.promoteCertainAICategories(...) usando la stessa soglia configurata dallo slider "Soglia confidence", esattamente come il path post-scan in AppState+Scanning.runPostScanCategoryAnalysis. Eliminata un'asimmetria storica fra i due path.

Note sui prodotti operativi: per i progetti onboarded con cataloghi molto grandi (>5k SKU), il campo "Note" del prodotto resta vuoto al primo sync. Verrà ripopolato in un rilascio successivo via update chunked dedicato.

Per forzare il check di aggiornamento via terminale:

defaults delete zannato.Nostar SULastCheckTime
