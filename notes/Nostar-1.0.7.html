Nostar 1.0.7

Catalogo prodotti riprogettato in chiave lookup-first, codici invito permanenti opzionali, e una serie di miglioramenti di qualità di vita su rinomina file e scan mirato.

Novità

  • Wizard catalogo riprogettato: nuovo flusso di import che riconosce header internazionali, gestisce sheet duplicati o cancellati, deduplica varianti su barcode multipli e tollera totali/subtotali nei file Excel reali. Anteprima live prima della conferma.
  • Codici invito permanenti: oltre al classico TTL 24h/7g, ora puoi generare codici senza scadenza, revocabili manualmente dal Project Hub. Utile per progetti long-running con onboarding continuo.
  • Rinomina file inline: doppio clic sul nome file nella tabella per rinominare al volo, con preview percorso, validazione caratteri Finder e rollback automatico in caso di conflitto.
  • Scope attivo dello scan: nuovo modello di selezione gerarchica che limita la pipeline a sottocartelle o categorie scelte, senza re-scan globale. Badge "shots" nella tabella mostra il numero di scatti completati per riga.
  • Vision AI configurabile: nel pannello Vision AI delle impostazioni progetto puoi regolare le soglie di promozione SigLIP (quando una predizione diventa "primary", quando viene rigettata). Reset al default sempre disponibile.

Note tecniche

Lato server (Cloudflare Worker): migration 0016_permanent_project_invite_codes rende opzionale expires_at sulla tabella inviti; migration 0017_operational_category_source_compat abilita il nuovo discriminator di sorgente per le categorie operative. Nuovi endpoint POST /invites con flag permanent e DELETE /invites/:code per revoca.

Lato app: ProjectCatalogImportService riscritto in stile lookup-first con suite di 15 fixture Excel reali coperte da test deterministici (CatalogImportNormalizerTests, ExcelServiceSheetResolutionTests, CategoryTemplateDatabaseTests). Pipeline scan isolata in ScanFileEnumerator + ScanResultAssembler con coverage del 90%+. InlineFileRenameRequest incapsula la transazione di rinomina con rollback su conflitto.

Per forzare il check di aggiornamento via terminale:

defaults delete zannato.Nostar SULastCheckTime
