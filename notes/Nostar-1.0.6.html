Nostar 1.0.6

Nuova sezione "Codici di invito" nel Project Hub per recuperare i codici Nostar attivi di un progetto cloud, anche dopo aver chiuso il wizard di creazione.

Novità

  • Recupero codici di invito: nel Project Hub, sotto la "Dashboard cliente", la nuova sezione "Codici di invito" mostra i codici Nostar attivi del progetto (non scaduti, non ancora usati). Da qui puoi copiare un codice negli appunti o condividerlo via AirDrop, Mail o Messaggi, e generare un nuovo codice senza dover ricreare il progetto.
  • Cinque stati gestiti: cloud disattivato, caricamento, errore con retry, lista vuota con CTA "Genera nuovo codice", lista codici con data di creazione.

Note tecniche

Lato server (Cloudflare Worker): nuovo endpoint GET /api/projects/:id/invites autenticato via project token. Restituisce solo codici ancora validi (used_at IS NULL AND (expires_at IS NULL OR expires_at > now())), ordinati per data di creazione decrescente. Rate limit dedicato list_invites: 60/60s.

Lato app: CloudGatewayClient.listInvites(projectID:token:) con retry trasparente su errori transitori, nuovo modello CloudInvitePayload e UI NostarProjectHubInvitesSection coerente con i controlli di condivisione codice già presenti nello step Conferma del wizard progetto.

Per forzare il check di aggiornamento via terminale:

defaults delete zannato.Nostar SULastCheckTime
