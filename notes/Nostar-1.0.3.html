Nostar 1.0.3

Release focalizzata su sync multi-set cloud e categorizzazione automatica SigLIP. Diversi fix critici alla pipeline Vision AI emersi durante test su progetti reali.

Categorizzazione automatica SigLIP

  • I prodotti con un solo file senza suffisso vista (es. SKU.jpg) ora vengono categorizzati automaticamente. Prima venivano silenziosamente skippati dal pipeline AI.
  • Lo slider "Soglia confidence" nelle impostazioni Vision AI è ora sempre interattivo e controlla effettivamente quali suggerimenti SigLIP vengono promossi a categoria.
  • Soglia di default abbassata da 0.70 a 0.10, coerente con il range reale di SigLIP2 (0.05-0.40), non con la scala softmax legacy.
  • L2-normalize defensive dell'embedding immagine: confidence ora nel range atteso, non più anomalamente basse.
  • Il rinomina file dopo lo scan iniziale (per match SKU Excel) triggera ora la categorizzazione AI in automatico.
  • Engine SigLIP CoreML attivo di default per i nuovi progetti.

Sync cloud multi-set

  • Quando più Mac sono linkati allo stesso progetto cloud, le modifiche operative si propagano entro 60 secondi. Il watcher fa polling della firma del progetto e re-importa solo se cambiata.
  • Nuovo endpoint Worker GET /api/projects/:id/version con auth Bearer per check signature efficienti.
  • Re-upload Excel dalla dashboard web ora viene importato come source-of-truth dagli altri set linkati.
  • Layer di retry + chunking + progress + diagnostics sulle chiamate cloud, con backoff esponenziale e logging strutturato.
  • La dashboard cloud mostra ora solo prodotti con preview caricate, non l'intero catalogo Excel.

UI & UX

  • Tab "Errori" mostra correttamente la ErrorTableView quando ci sono errori ma nessun prodotto in tabella (era dead code).
  • Overlay di creazione progetto con fasi visibili durante il wizard cloud-enabled.
  • Pulizia recents orfani dopo l'eliminazione di un progetto.
  • Widget di progress QC ora si pulisce correttamente al deactivate del progetto.
  • Selettore catalogo mostra progetti B2B dal DB con recents standalone separati.

Stabilità

  • Re-import: persistenza del mapping precedente + warning banner su state leak.
  • Localizzazione: stringhe scoperte da Xcode aggiornate.
