# Nostar Releases — Sparkle feed

Repo dedicato al feed Sparkle di [Nostar](https://github.com/zannato/Nostar).

- `appcast.xml` — feed Sparkle 2.x consumato dall'app.
- `notes/` — release notes per ogni versione (`Nostar-X.Y.Z.html`).
- I binari ZIP notarizzati sono pubblicati come asset delle GitHub Release.

Pubblicazione automatica via [.github/workflows/release.yml](https://github.com/zannato/Nostar/blob/main/.github/workflows/release.yml) del repo principale.
